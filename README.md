# PhDschool2026_AppML

GitHub repository for 2026 AIPHY Ph.D. school on Applied Machine Learning in Orsay, Paris.

This GitHub contains four exercises, from which you can choose some/all to work on. They represent "everything" from simple classification with BDTs/NNs to CNNs, GNNs, VAEs, and all the way to a (Shakespearian) language transformer.
